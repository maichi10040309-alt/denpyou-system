# 振替伝票システム

Excel（振替伝票マクロブック）で行っていた月次の振替伝票入力・作成・集計業務を、ブラウザだけで使えるWebアプリにしたものです。インストール不要で、URLを開くだけで利用できます。

## できること

- **伝票入力シート**：1か月分の取引（日付・金額・借方科目・摘要・貸方科目・金額2・課非）を一覧入力。日付欄はカレンダーからの選択と直接入力の両方に対応（「8/10」「10」のような略記も自動変換）。日付・金額・科目・摘要での絞り込みと、日付列の並べ替え（昇順・降順）に対応
- **振替伝票作成**：入力データから日付ごとに1枚の振替伝票を自動生成（印刷対応）
- **振替伝票まとめ**：当月の全伝票をまとめて印刷できるビュー
- **経費集計表**：資産科目（現金・預金口座）を除いた借方科目を、摘要の先頭記号（⑩厨房／⑳介護／㊵治療院・エステ）から部署別に自動集計。人件費は部署ごとに直接入力でき、自動集計分と合わせて合計・部署別カードに反映される
- **売上集計表**：売上・家賃収入・雑収入を部署別に自動集計
- **科目マスタ／摘要マスタ／定期支払マスタ**：入力候補や自動仕訳のもとになるデータを管理
- **定期入力**：定期支払マスタから当月分（リース・月額）を伝票入力シートへ一括挿入
- **月管理**：新規月の作成、月の切り替え、データのバックアップ（エクスポート）／復元（インポート）
- **Excel取込**：今お使いのExcel振替伝票ファイル（.xlsx/.xlsm）の「入力シート」をそのまま読み込み、取引データを取り込み（複数ファイルの一括取込、既存月への追加／置き換えにも対応）
- **Excel保存**：月ごとに「入力シート」「日付ごとの振替伝票」「経費集計表」「売上集計表」をまとめた.xlsxファイルを書き出し、従来どおりExcelでの保管が可能（伝票入力シート・月管理の両画面から実行可）
- **仕入れ経費**：別管理の仕入れ管理Excel（業者名・科目・請求額の形式）を取り込み、振替伝票を作らずに経費集計にのみ反映。科目の対応付けを確認しながら取り込め、取り込んだデータは一覧で確認・編集・削除できる

## データの保存について

このシステムはサーバーを持たず、**データはお使いのブラウザ内（localStorage）にのみ保存**されます。そのため：

- 同じブラウザ・同じ端末からアクセスする限り、データは自動的に保存され続けます。
- ブラウザを変えたり、別の端末からアクセスすると、データは共有されません。
- ブラウザの閲覧データ（サイトデータ）を消去すると、入力したデータも失われます。

**「月管理」画面の「全データをエクスポート」で定期的にバックアップを取得することを強くおすすめします。** バックアップファイル（JSON）は「バックアップから復元」でいつでも読み込めます。

## ローカルで動かす場合

ビルド不要の素のHTML/CSS/JavaScriptです。ブラウザのモジュール読み込み制限のため、`file://` で直接開くのではなく簡易サーバーで配信してください。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## 公開（デプロイ）方法

GitHub Pages 用のワークフロー（`.github/workflows/pages.yml`）を同梱しています。リポジトリの **Settings → Pages → Build and deployment → Source** を「GitHub Actions」に設定すると、このブランチ（または main）へのプッシュのたびに自動でURLが発行・更新されます。設定後のURLは `https://<ユーザー名>.github.io/<リポジトリ名>/` の形式になります。

## 用語・仕様メモ

- 摘要の先頭が「⑩」→ 厨房、「⑳」→ 介護、「㊵」→ 治療院・エステ、として部署を自動判定します（元のExcelマクロと同じルールです）。
- 経費集計は「借方科目が資産科目（現金・普通預金など）でない」かつ「摘要から部署が判定できる」行のみを対象にします。科目マスタで「資産科目」にチェックした科目は自動的に除外されます。
- 売上集計は「貸方科目が 売上／家賃収入／雑収入 のいずれか」の行を対象にします。
- Excel取込は「入力シート」のB2（年）・B3（月）と7行目以降のA〜H列を読み取ります。ファイルの中身はブラウザ内でその場で処理されるだけで、外部に送信されることはありません。
- Excel保存も同様にブラウザ内で.xlsxファイルを生成するだけで、外部への送信はありません。ファイル名は「振替伝票_YYYY年MM月.xlsx」になります。
- 仕入れ経費として取り込んだデータは、振替伝票まとめには一切表示されず、経費集計にのみ加算されます。伝票入力シートの合計額・差額のチェックにも影響しません。
- 伝票入力シートの絞り込み・並べ替えは表示のみに影響し、合計額・差額の計算は常に全行を対象にします。行を追加すると絞り込み・並べ替えは自動的に解除され、新しい行がすぐ見えるようになります。
- 絞り込みは全角/半角（カナ・数字など）の表記ゆれを吸収するので、どちらで入力しても一致します。日付欄は「2026-08-10」「8/10」「10（日のみ）」「8月10日」など柔軟な書き方に対応し、確定時に日付形式へ自動変換されます。
- 経費集計表の人件費は月・部署ごとに保存され、伝票入力データとは別管理です。金額を入力すると科目別表・合計カード・Excel書き出しに自動で反映されます（未入力の部署は0円として扱われ、Excel書き出しでは1円も入力されていなければ人件費の行自体を省略します）。
